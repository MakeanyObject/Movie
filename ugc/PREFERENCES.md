# 영상 생성 선호 설정 (사용자 지정)

## 모델 선택
- **기본: 저렴한 영상 모델 사용** (예: Kling 등). seedance 2.5는 기본 사용 금지.
- 적용 시점: 2026-09-12 이후 모든 영상 생성.

## 대사 처리 방식 (확정)
- **나레이션(보이스오버) + 자막 번인** 방식으로 통일. 립싱크(입모양 대사) 방식은 사용 안 함.
- 따라서 영상은 **저가 모델(Kling 등)로 비주얼만 생성**하고(등장인물은 말하지 않거나 자연스러운 액션),
  대사는 **별도 나레이션 오디오 + 화면 자막**으로 전달.

## 표준 제작 파이프라인 (대사 있는 영상)
1. 비주얼: **Kling 등 저가 모델**로 클립 생성 (립싱크 불필요, 무음/액션 위주).
2. 나레이션: 대본을 **TTS(create_voice / generate_audio)** 로 음성 생성 (재사용 보이스 지정 권장).
3. 합성: 나레이션 오디오를 영상에 mux + **자막 번인**(whisper 타이밍, subtitles 워크플로우).
4. 최종 9:16 MP4 출력.

## 재사용 나레이션 보이스
- **한국어 여성 / 밝고 친근한 톤** (숏폼·제품 리뷰용). 매 영상 동일 적용.
- 구체 voice_id는 다음 영상 착수 시 list_voices에서 선정해 여기에 고정.

## 적용 범위
- 현재 우산 영상(깨끗한 피부 버전)은 완성본으로 마무리 — 소급 적용 안 함.
- **다음 영상부터** 위 파이프라인(저가 모델 + 한국어 여성 나레이션 + 자막) 적용.

## 품질 검수(QA) 운영 방식 — 합의
- 현재는 제작 빈도가 낮으므로 **사람(사용자)이 직접 검수**하는 human-in-the-loop 방식.
- 절차: ① 사용자가 컷별로 확인 → ② 어색한 부분을 Claude와 함께 해결법 실험 →
  ③ **효과 본 방법을 `PLAYBOOK.md`에 축적** → ④ 다음 영상부터 재사용.
- 대량 자동화가 필요해지면 그때 ③(video_analysis)·④(프레임+멀티모달) 자동 검수로 승격.

### 사용자 검수용 체크리스트 (특히 "사용법 자연스러움")
- [ ] 제품 사용 인과가 맞는가 (예: 버튼 누름 → 실제로 펴짐)
- [ ] 손 개수/그립 자연스러운가 (여분 손·팔 없음)
- [ ] 제품이 하나로 일관(색·디자인 동일, 복제 없음)
- [ ] 입모양/음성 싱크(립싱크 방식일 때) 또는 자막 타이밍(나레이션 방식일 때)
- [ ] 얼굴/헤어 일관성, 피부 톤
