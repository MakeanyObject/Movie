# 영상 생성 선호 설정 (사용자 지정)

## 모델 선택
- **기본: 저렴한 영상 모델 사용** (예: Kling 등). seedance 2.5는 기본 사용 금지.
- 적용 시점: 2026-09-12 이후 모든 영상 생성.

### 단, 예외/주의 (토킹헤드 UGC)
- **네이티브 음성(입모양 싱크) 대사**가 필요한 토킹헤드 UGC는 seedance_2_5(`omni_reference` + `generate_audio`)가 대사를 직접 렌더링합니다.
- Kling 등 저가 모델은 **네이티브 대사/립싱크를 생성하지 않음** → 대사가 필요하면
  1) 무음/보이스오버(TTS) 별도 생성 + 립싱크, 또는
  2) 대사 없는 포맷(제품 위주/B-roll)으로 진행.
- 따라서 **대사 있는 UGC**는 진행 전에 "저가 모델(대사 방식 변경)로 갈지 / seedance로 갈지" 한 번 확인.
- **대사 없는 영상**(제품 모션, B-roll, 분위기 컷 등)은 기본적으로 Kling 등 저가 모델로 생성.
