# 영상 생성 선호 설정 (사용자 지정)

## 모델 선택
- **기본: 저렴한 영상 모델 사용** (예: Kling 등). seedance 2.5는 기본 사용 금지.
- 적용 시점: 2026-09-12 이후 모든 영상 생성.

## 대사 처리 방식 (확정)
- **나레이션(보이스오버) + 자막 번인** 방식으로 통일. 립싱크(입모양 대사) 방식은 사용 안 함.
- 따라서 영상은 **저가 모델(Kling 등)로 비주얼만 생성**하고(등장인물은 말하지 않거나 자연스러운 액션),
  대사는 **별도 나레이션 오디오 + 화면 자막**으로 전달.

## 표준 제작 파이프라인 (대사 있는 영상)
1. 비주얼: **Kling 등 저가 모델**로 클립 생성 (립싱크 불필요, 무음/액션 위주).
2. 나레이션: 대본을 **TTS(create_voice / generate_audio)** 로 음성 생성 (재사용 보이스 지정 권장).
3. 합성: 나레이션 오디오를 영상에 mux + **자막 번인**(whisper 타이밍, subtitles 워크플로우).
4. 최종 9:16 MP4 출력.

## 재사용 나레이션 보이스
- (미지정) — 원하는 보이스 톤/성별을 정하면 고정해서 매 영상에 동일 적용.
